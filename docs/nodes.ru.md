# Справочник блоков

Сгенерировано из реестра нод (`scripts/gen-nodes.mjs`). Типы пинов: `exec` (порядок выполнения), `string`, `number`, `boolean`, `element`, `elements`, `event`, `object`, `any`. Текст на пине элемента — это CSS-селектор.

## События

### Событие элемента — `event.element`

Срабатывает при событии на элементе, подходящем под селектор, — на всех страницах и для элементов, добавленных позже. Без селектора — сам корень (элемент компонента).

- **Входы:** —
- **Выходы:** `exec`, `element` Элемент, `event` Событие
- **Настройки:** Селектор (`selector`), Событие (`event` = `"click"`; `click` `dblclick` `contextmenu` `mousedown` `mouseup` `mouseenter` `mouseleave` `pointerdown` `pointerup` `touchstart` `touchend` `input` `change` `submit` `reset` `focus` `blur` `keydown` `keyup` `animationend` `transitionend`), Отменить действие браузера (`preventDefault` = `false`), Остановить всплытие (`stopPropagation` = `false`), Только один раз (`once` = `false`)

### При запуске — `event.start`

Срабатывает один раз при запуске: когда страница готова или когда появился экземпляр компонента.

- **Входы:** —
- **Выходы:** `exec`, `element` Корень

### Событие страницы — `event.page`

События окна и документа: загрузка, прокрутка, изменение размера, смена hash, видимость вкладки…

- **Входы:** —
- **Выходы:** `exec`, `event` Событие
- **Настройки:** Событие (`event` = `"scroll"`; `load` `scroll` `resize` `hashchange` `popstate` `visibilitychange` `online` `offline` `beforeunload`), Не чаще, мс (`throttle` = `0`)

### Таймер — `event.timer`

Срабатывает через заданное время или каждые N миллисекунд, если включён «Повтор».

- **Входы:** —
- **Выходы:** `exec`
- **Настройки:** Миллисекунды (`ms` = `1000`), Повтор (`repeat` = `false`)

### Клавиша — `event.key`

Срабатывает при нажатии клавиши на странице (например Escape). Пустая клавиша — любая.

- **Входы:** —
- **Выходы:** `exec`, `event` Событие
- **Настройки:** Клавиша (`key` = `"Escape"`; `Escape` `Enter` ` ` `ArrowLeft` `ArrowRight` `ArrowUp` `ArrowDown` `Tab`), Событие (`event` = `"keydown"`; `keydown` `keyup`), Ctrl / ⌘ (`ctrl` = `false`), Shift (`shift` = `false`), Alt (`alt` = `false`), Отменить действие браузера (`preventDefault` = `false`)

### Своё событие — `event.custom`

Срабатывает, когда до корня доходит событие с этим именем (см. «Отправить событие»). Так блюпринты общаются между собой.

- **Входы:** —
- **Выходы:** `exec`, `any` Данные, `element` Отправитель
- **Настройки:** Имя события (`name` = `"my-event"`)

## Поток

### Условие — `flow.branch`

Если условие истинно — выполняет «Да», иначе «Нет».

- **Входы:** `exec`, `boolean` Условие = `false`
- **Выходы:** `exec` Да, `exec` Нет

### Последовательность — `flow.sequence`

Выполняет выходы по очереди сверху вниз.

*пины зависят от настроек*

- **Входы:** `exec`
- **Выходы:** `exec` Затем 0, `exec` Затем 1
- **Настройки:** Выходы (`count` = `2`)

### Задержка — `flow.delay`

Ждёт, потом продолжает.

- **Входы:** `exec`, `number` Миллисекунды = `300`
- **Выходы:** `exec`

### Debounce — `flow.debounce`

Продолжает только когда вызовы прекратились на заданное время (ввод текста, ресайз).

- **Входы:** `exec`, `number` Миллисекунды = `300`
- **Выходы:** `exec`

### Throttle — `flow.throttle`

Продолжает не чаще, чем раз в заданное время.

- **Входы:** `exec`, `number` Миллисекунды = `200`
- **Выходы:** `exec`

### Один раз — `flow.doOnce`

Продолжает только в первый раз — до «Сброса».

- **Входы:** `exec`, `exec` Сброс
- **Выходы:** `exec`

### Для каждого — `flow.forEach`

Выполняет «Тело цикла» для каждого элемента (найденные элементы, массив…), затем «Завершено».

- **Входы:** `exec`, `any` Элементы
- **Выходы:** `exec` Тело цикла, `any` Элемент, `number` Индекс, `exec` Завершено

### Выбор — `flow.switch`

Выполняет выход, чей вариант равен значению, иначе «По умолчанию». Варианты — через запятую.

*пины зависят от настроек*

- **Входы:** `exec`, `any` Значение
- **Выходы:** `exec` a, `exec` b, `exec` По умолчанию
- **Настройки:** Варианты (`cases` = `"a, b"`)

## Элементы

### Найти элементы — `dom.query`

Находит элементы по CSS-селектору: во всём документе (или компоненте), внутри заданных элементов или ближайшего предка.

- **Входы:** `string` Селектор, `elements` От
- **Выходы:** `elements` Элементы, `element` Первый, `number` Количество
- **Настройки:** Где (`mode` = `"all"`; `all` `within` `closest`)

### Корневой элемент — `dom.root`

Элемент компонента (для компонентных блюпринтов) или <html> (для страничных).

- **Входы:** —
- **Выходы:** `element` Элемент

### Добавить класс — `dom.addClass`

Добавляет класс(ы) элементам. Несколько классов — через пробел.

- **Входы:** `exec`, `elements` Цель, `string` Класс
- **Выходы:** `exec`

### Убрать класс — `dom.removeClass`

Убирает класс(ы) у элементов.

- **Входы:** `exec`, `elements` Цель, `string` Класс
- **Выходы:** `exec`

### Переключить класс — `dom.toggleClass`

Добавляет класс, если его нет, иначе убирает.

- **Входы:** `exec`, `elements` Цель, `string` Класс
- **Выходы:** `exec`

### Есть класс — `dom.hasClass`

Истина, если хотя бы у одного элемента есть класс.

- **Входы:** `elements` Цель, `string` Класс
- **Выходы:** `boolean` Результат

### Подходит под селектор — `dom.matches`

Истина, если элемент подходит под CSS-селектор (например, клик был по самому фону).

- **Входы:** `element` Элемент, `string` Селектор
- **Выходы:** `boolean` Результат

### Задать атрибут — `dom.setAttribute`

Задаёт атрибут (aria-expanded, data-state…).

- **Входы:** `exec`, `elements` Цель, `string` Имя, `string` Значение
- **Выходы:** `exec`

### Убрать атрибут — `dom.removeAttribute`

Убирает атрибут.

- **Входы:** `exec`, `elements` Цель, `string` Имя
- **Выходы:** `exec`

### Прочитать атрибут — `dom.getAttribute`

Атрибут первого элемента (пустая строка, если нет).

- **Входы:** `elements` Цель, `string` Имя
- **Выходы:** `string` Значение

### Задать стиль — `dom.setStyle`

Задаёт inline CSS-свойство (пустое значение убирает его).

- **Входы:** `exec`, `elements` Цель, `string` Свойство, `string` Значение
- **Выходы:** `exec`

### Задать текст — `dom.setText`

Заменяет текст элементов (безопасно: HTML не разбирается).

- **Входы:** `exec`, `elements` Цель, `string` Текст
- **Выходы:** `exec`

### Прочитать текст — `dom.getText`

Текст первого элемента.

- **Входы:** `elements` Цель
- **Выходы:** `string` Текст

### Задать HTML (небезопасно) — `dom.setHtml`

Заменяет внутренний HTML. Никогда не передавайте сюда ввод пользователя: это может запустить чужой скрипт (XSS). Лучше «Задать текст».

- **Входы:** `exec`, `elements` Цель, `string` HTML
- **Выходы:** `exec`

### Прочитать значение — `dom.getValue`

Значение первого поля формы (флажок — отмечен или нет).

- **Входы:** `elements` Цель
- **Выходы:** `any` Значение

### Задать значение — `dom.setValue`

Задаёт значение полей формы (флажок отмечается, если значение истинно).

- **Входы:** `exec`, `elements` Цель, `any` Значение
- **Выходы:** `exec`

### Показать — `dom.show`

Делает скрытые элементы видимыми (убирает display: none / hidden).

- **Входы:** `exec`, `elements` Цель
- **Выходы:** `exec`

### Скрыть — `dom.hide`

Скрывает элементы (display: none).

- **Входы:** `exec`, `elements` Цель
- **Выходы:** `exec`

### Показать / скрыть — `dom.toggleVisible`

Показывает скрытые элементы и скрывает видимые.

- **Входы:** `exec`, `elements` Цель
- **Выходы:** `exec`

### Виден ли — `dom.isVisible`

Истина, если первый элемент отображается.

- **Входы:** `elements` Цель
- **Выходы:** `boolean` Результат

### Фокус — `dom.focus`

Переводит фокус клавиатуры на элемент.

- **Входы:** `exec`, `elements` Цель
- **Выходы:** `exec`

### Прокрутить к — `dom.scrollIntoView`

Прокручивает страницу к элементу.

- **Входы:** `exec`, `elements` Цель, `boolean` Плавно = `true`
- **Выходы:** `exec`

### Отправить событие — `dom.dispatch`

Отправляет своё событие от элементов (всплывает). Другие блюпринты ловят его блоком «Своё событие». Пустая цель — корень блюпринта.

- **Входы:** `exec`, `elements` Цель, `string` Имя события = `"my-event"`, `any` Данные
- **Выходы:** `exec`

### Отменить действие браузера — `event.preventDefault`

Отменяет действие браузера по событию (переход по ссылке, отправку формы).

- **Входы:** `exec`, `event` Событие
- **Выходы:** `exec`

### Цель события — `event.target`

Элемент, на котором событие произошло на самом деле (может быть потомком слушаемого).

- **Входы:** `event` Событие
- **Выходы:** `element` Цель

## Данные

### Текст — `data.string`

Текстовое значение.

- **Входы:** `string` Значение
- **Выходы:** `string` Значение

### Число — `data.number`

Числовое значение.

- **Входы:** `number` Значение = `0`
- **Выходы:** `number` Значение

### Да/нет — `data.boolean`

Логическое значение.

- **Входы:** `boolean` Значение = `false`
- **Выходы:** `boolean` Значение

### Склеить текст — `string.concat`

Склеивает два текста с необязательным разделителем.

- **Входы:** `string` A, `string` B, `string` Разделитель
- **Выходы:** `string` Результат

### В число — `convert.number`

Преобразует значение в число (0, если это не число).

- **Входы:** `any` Значение
- **Выходы:** `number` Число

### В текст — `convert.string`

Преобразует значение в текст (объекты — в JSON).

- **Входы:** `any` Значение
- **Выходы:** `string` Текст

### Прочитать из хранилища — `storage.get`

Значение, сохранённое в браузере (localStorage) под ключом; пусто, если нет.

- **Входы:** `string` Клавиша
- **Выходы:** `string` Значение

### Сохранить в хранилище — `storage.set`

Сохраняет значение в браузере (localStorage); переживает перезагрузку.

- **Входы:** `exec`, `string` Клавиша, `string` Значение
- **Выходы:** `exec`

### Объект (JSON) — `data.object`

Объект или массив в виде JSON — например настройки библиотеки: `{ "loop": true, "speed": 600 }`.

- **Входы:** —
- **Выходы:** `object` Объект
- **Настройки:** JSON (`json`)

## Переменные

### Прочитать переменную — `var.get`

Значение переменной блюпринта.

- **Входы:** —
- **Выходы:** `any` Значение
- **Настройки:** Переменная (`variable`)

### Записать переменную — `var.set`

Сохраняет значение в переменную блюпринта (живёт, пока открыта страница).

- **Входы:** `exec`, `any` Значение
- **Выходы:** `exec`, `any` Значение
- **Настройки:** Переменная (`variable`)

### Параметр компонента — `component.param`

Значение параметра компонента (задаётся в трейтах). Только для компонентных блюпринтов.

- **Входы:** —
- **Выходы:** `any` Значение
- **Настройки:** Параметр (`param`)

## Математика

### Математика — `math.op`

Арифметика двух чисел. Деление на ноль даёт 0.

- **Входы:** `number` A = `0`, `number` B = `0`
- **Выходы:** `number` Результат
- **Настройки:** Операция (`op` = `"+"`; `+` `-` `*` `/` `%` `min` `max` `pow`)

## Логика

### Сравнить — `logic.compare`

Сравнивает два значения. «==» сравнивает нестрого ("1" равно 1).

- **Входы:** `any` A, `any` B
- **Выходы:** `boolean` Результат
- **Настройки:** Оператор (`op` = `"=="`; `==` `!=` `<` `>` `<=` `>=`)

### И — `logic.and`

Истина, если оба истинны.

- **Входы:** `boolean` A = `false`, `boolean` B = `false`
- **Выходы:** `boolean` Результат

### ИЛИ — `logic.or`

Истина, если хотя бы одно истинно.

- **Входы:** `boolean` A = `false`, `boolean` B = `false`
- **Выходы:** `boolean` Результат

### НЕ — `logic.not`

Инвертирует логическое значение.

- **Входы:** `boolean` Значение = `false`
- **Выходы:** `boolean` Результат

## Код

### JavaScript — `code.js`

Свой код. Входы — в `inputs`, верните объект с выходами (`return { result: 42 };`). В `ctx` есть `root`, `document`, `window`, `params`. С «Асинхронно» верните Promise: цепочка продолжится, когда он выполнится.

*пины зависят от настроек*

- **Входы:** `exec`, `any` value
- **Выходы:** `exec`, `any` result
- **Настройки:** Код (`code`), Входы (`inputs` = `[{"id":"value","type":"any"}]`), Выходы (`outputs` = `[{"id":"result","type":"any"}]`), Асинхронно (`async` = `false`)

### Выражение — `code.expression`

JavaScript-выражение от `a` и `b`, например `a * 2 + b` или `a.trim()`.

- **Входы:** `any` a, `any` b
- **Выходы:** `any` Результат
- **Настройки:** Выражение (`expression`)

### Вызвать функцию — `lib.call`

Вызывает глобальную функцию, например из библиотеки: `gsap.to`, `AOS.init`, `alert`. Аргументы передаются по порядку.

*пины зависят от настроек*

- **Входы:** `exec`, `any` Аргумент 1
- **Выходы:** `exec`, `any` Результат
- **Настройки:** Функция (`fn` = `"console.log"`), Аргументов (`args` = `1`)

### Создать объект — `lib.new`

Создаёт объект класса библиотеки: `new Swiper(элемент, настройки)`, `new Chart(canvas, config)`.

*пины зависят от настроек*

- **Входы:** `exec`, `any` Аргумент 1, `any` Аргумент 2
- **Выходы:** `exec`, `object` Объект
- **Настройки:** Класс (`cls` = `"Swiper"`), Аргументов (`args` = `2`)

### Вызвать метод — `lib.method`

Вызывает метод объекта, например `slideNext` у Swiper или `play` у видео.

*пины зависят от настроек*

- **Входы:** `exec`, `any` Объект
- **Выходы:** `exec`, `any` Результат
- **Настройки:** Метод (`method`), Аргументов (`args` = `0`)

### Глобальное значение — `lib.get`

Читает глобальное значение: `location.pathname`, `innerWidth`, объект библиотеки.

- **Входы:** —
- **Выходы:** `any` Значение
- **Настройки:** Имя (`name` = `"location.pathname"`)

## Отладка

### Вывести в консоль — `debug.log`

Пишет значение в консоль браузера.

- **Входы:** `exec`, `string` Подпись, `any` Значение
- **Выходы:** `exec`
